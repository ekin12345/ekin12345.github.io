D U N E  ·  探明洞穴与道路

规 则

  • 目标：操作指针，用尽量少的步数探明这个迷宫共有多少个洞穴、多少条道路。
  • 图的性质：连通图，不保证无重边，不保证无自环，不保证是平面图。
  • look查看当前结点：返回与它相连的边数，以及路标是否在此洞穴。
  • put_sign在当前结点放上路标。仅当路标随身携带时可用。
  • take_sign拿走当前结点的路标。仅当路标在此洞穴时可用。
  • walk i沿着编号为 i 的边走到相邻结点，计 1 步。与某结点相连的 d 条边按逆时针顺序编号 0,1,…,d−1。走第一步时，编号 0 的边由游戏随机确定；以后，游戏会把「进入这个结点的那条边」编号为 0。
  • report n m报告洞穴数 n 与道路数 m。正确即通关。
  • 洞穴数 n、道路数 m 的范围由你在下方「设置」中指定（需满足 n ≥ 4、m ≥ n − 1）。
